Do not paste real API keys, Discord webhook URLs, GitHub tokens, Naver credentials, or private identifiers into public issues, pull requests, screenshots, logs, or documentation.

For v0.2.x, Discord webhook URLs remain GitHub Secrets, runtime settings remain GitHub Variables, and `ko-KR` legacy webhook fallback behavior remains supported. If a secret is exposed, revoke or rotate it before continuing workflow runs.
