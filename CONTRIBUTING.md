# Contributing

Choose a language.

| 한국어 | English |
| --- | --- |
| [기여 안내](./docs/kr/CONTRIBUTING.md) | [Contributing guide](./docs/en/CONTRIBUTING.md) |

Before opening a pull request, run the relevant validation commands and do not include secrets, webhook URLs, private Discord details, or personal identifiers.

Keep pull requests small and focused. Avoid unrelated refactors, generated `reports/` artifacts, fake adoption metrics, and claims that `en-US` or provider support is more mature than the current v0.2 implementation proves.

For behavior changes, keep Korean and English docs aligned and preserve `ko-KR` v0.2 compatibility unless a later breaking release is explicitly planned.
