# Contribution Guide Index

## Start here

이 디렉터리는 Career Feed에 기여할 때 참고할 세부 가이드를 모아 둔 index입니다.

루트의 [Contributing](../../CONTRIBUTING.md)을 먼저 읽고, 커뮤니티 기대 사항은 [Code of Conduct](../../CODE_OF_CONDUCT.md)를 확인해 주세요.

Career Feed는 백엔드 지망생과 주니어 개발자가 학습 주제, 커리어 정보, OSS 후보, 기술 뉴스, PS 루틴을 덜 막막하게 탐색하도록 돕는 초기 단계의 공개 OSS입니다.

이 문서들은 기여를 막기 위한 규칙이 아니라, 좋은 제안을 더 빠르고 안전하게 검토하기 위한 기준입니다.

## Contribution paths

기여 경로는 크게 네 가지입니다.

- 백엔드 학습 주제와 roadmap 개선
- 정보 출처 제안
- beginner-friendly OSS 후보 제안
- 백엔드 커리어 질문과 문서 개선

검증 스크립트 개선이나 지역·언어 확장 아이디어도 환영합니다.

큰 workflow 변경이나 새 지역 추가는 PR 전에 issue로 먼저 논의해 주세요.

## Suggestion quality

좋은 제안은 작고 검토 가능합니다.

좋은 제안은 누구에게 도움이 되는지 설명합니다.

좋은 제안은 공개적으로 확인 가능한 URL이나 근거를 포함합니다.

좋은 제안은 maintainer가 검토할 수 있는 자료로 제출됩니다.

자세한 기준은 [Good suggestion criteria](good-suggestion-criteria.md)를 참고해 주세요.

## Regional and language expansion

지역 또는 언어 확장 제안은 환영합니다.

다만 모든 국가와 언어를 이미 지원한다고 주장하지 않습니다.

새 지역 제안에는 region, locale, language, timezone, source reliability, public availability를 함께 적어 주세요.

지역 제안은 바로 workflow에 반영되지 않고 maintainer review를 거칩니다.

source policy와 검증 가능성이 충분해야 다음 단계로 갈 수 있습니다.

## Maintainer review

Maintainer는 제안을 프로젝트 범위, 안전성, 유지보수 가능성 기준으로 검토합니다.

거절은 contributor 개인에 대한 평가가 아닙니다.

필요하면 더 많은 맥락을 요청하거나, 더 작은 범위로 나누도록 요청할 수 있습니다.

자세한 검토 기준은 [Maintainer review policy](review-policy.md)를 참고해 주세요.
