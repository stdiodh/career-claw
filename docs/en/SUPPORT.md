# Support

> Language: [한국어](../kr/SUPPORT.md) | [English](./SUPPORT.md)

Support for Career Feed is handled through repository documentation and GitHub issues. Keep support requests specific and safe to discuss publicly.

## Where to ask

Use GitHub issues for bugs, documentation gaps, source suggestions, OSS candidate suggestions, and backend career questions. Choose the closest issue template.

## Before opening an issue

Check the [English docs](./README.md) first. Include the workflow name, command, input options, and artifact path when reporting a problem.

## Do not include secrets

Never paste API keys, Discord Webhook URLs, GitHub tokens, Naver credentials, or private log excerpts into a public issue.

## What support can cover

Support can cover fork setup, dry-run review, validation errors, document corrections, source quality questions, and safe OSS candidate policy.

## What support cannot guarantee

The project cannot guarantee job outcomes, investment advice, final career decisions, external site availability, or support for systems outside the initial automation scope.
