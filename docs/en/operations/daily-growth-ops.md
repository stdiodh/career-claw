# Daily Growth Ops

> Language: [한국어](../../kr/operations/daily-growth-ops.md) | [English](./daily-growth-ops.md)

Daily Growth Ops explains how to review the daily backend growth artifacts produced by Career Feed.

## Purpose

The goal is to turn daily output into practical study actions: one backend topic, one PS routine, one OSS preparation path, and one practical knowledge item.

## Dry-run review

Run the workflow in dry-run mode and inspect artifacts before enabling Discord delivery. Dry-run output is the safest review surface.

## Candidate artifacts

Important candidate files include backend practical knowledge, CS core daily topic, backend term daily, Spring/JVM study topic, OSS opportunities, and PS weekly routine JSON files.

## Growth interpretation

Read each item as a prompt for action. A good item has context, a small task, and a done criterion.

## No candidate days

If the OSS gate returns no safe candidates, the brief should show a preparation routine. This is a valid result.
