# Backend Growth Curriculum

> Language: [한국어](../../kr/operations/backend-growth-curriculum.md) | [English](./backend-growth-curriculum.md)

The backend growth curriculum provides practical knowledge items used by the Daily Backend Brief.

## Purpose

Each item should connect a realistic junior backend situation to concrete practice steps and done criteria.

## Tracks

Tracks may include API design, persistence, observability, performance, reliability, deployment, and collaboration topics.

## Lesson shape

A good lesson includes the track, situation, failure mode, practice steps, official references, and a clear result to review.

## Source policy

Prefer official documentation and stable references. Avoid broad or vague topic titles that do not produce a practical task.

## Review checklist

- Specific backend situation.
- Clear failure mode.
- Actionable practice steps.
- Official or stable references.
- No private data or secret values.
