# Backend Career Question Guide

> Language: [한국어](../../kr/contributing/backend-career-question-guide.md) | [English](./backend-career-question-guide.md)

Backend career questions help improve examples, learning prompts, and practical knowledge coverage when they are specific and safe to answer publicly.

## Purpose

Use this guide when asking about junior backend learning, portfolio direction, interview preparation, OSS practice, or daily study routines connected to Career Feed.

## What to include

- Your current target role or learning stage.
- The exact decision or blocker.
- Technologies involved, such as Java, Kotlin, Spring Boot, JVM, SQL, or GitHub Actions.
- What you have already tried.

## Good question examples

- How should I use the Daily Backend Brief artifacts to plan one week of Spring Boot study?
- Which validation artifact should I inspect when the OSS section falls back to preparation mode?
- What makes a backend portfolio source suggestion useful for this project?

## Weak question examples

- Tell me everything about backend jobs.
- Decide my career path for me.
- Review private company documents or personal data in public.

## Personal information safety

Remove phone numbers, addresses, private emails, private company data, webhook URLs, and credentials before opening an issue.

## How questions improve Career Feed

Good questions can become documentation examples, validation fixture ideas, or new checklist items for existing workflows.

## Maintainer review

Maintainers may rewrite titles, ask for missing context, or close questions that are too broad or outside the repository scope.
