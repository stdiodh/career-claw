# Source Suggestion Guide

> Language: [한국어](../../kr/contributing/source-suggestion-guide.md) | [English](./source-suggestion-guide.md)

Source suggestions improve the public inputs used by Career Feed workflows. They must be stable, public, and relevant to the active briefing paths.

## What counts as a source

A source can be an official documentation page, RSS feed, public repository, career page, event page, or other public page that can be reviewed without private access.

## Recommended source types

- Official Spring, JVM, Kotlin, and backend documentation.
- Public Korean developer and AI news sources.
- Public career, internship, event, hackathon, and contest pages.
- Public GitHub repositories and issue trackers.

## Source quality checklist

- Public URL is stable.
- Update cadence is visible or inferable.
- Content matches Career Feed scope.
- Page does not require secret credentials or private scraping.
- Regional and language context is clear.

## Region-specific source suggestions

For Korean sources, explain why the source matters to Korean backend learners. For English sources, link it only from the English tree unless it is shared configuration.

## Examples of strong source suggestions

- An official company careers page with backend internship postings.
- A Spring project documentation feed with stable URLs.
- A public conference page with developer session details.

## Examples of weak source suggestions

- A social media post without stable context.
- A page that blocks public review.
- A source unrelated to backend learning, developer news, or career discovery.

## Sources that may be rejected

Sources may be rejected when they are private, paywalled, unreliable, too broad, duplicative, or legally unsafe to collect.

## Privacy and scraping boundaries

Do not suggest sources that require collecting personal data, bypassing access controls, or scraping private user areas.

## Maintainer review flow

Maintainers verify source stability, relevance, duplicate coverage, and validation impact before accepting source changes.
