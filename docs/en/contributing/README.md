## Suggestion quality

A useful suggestion includes the source, why it matters to backend learners, freshness, regional or language context, and any safety limitations.

## Regional and language expansion

Language expansion should stay separate from the Korean and English trees unless the project deliberately adds a new tree. Shared images remain under `docs/assets/**`.

## Maintainer review

Maintainers prioritize correctness, small diffs, validation coverage, and source reliability. Broad roadmap changes should start as an issue.
