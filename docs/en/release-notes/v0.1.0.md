# v0.1.0 Release Notes

> Language: [한국어](../../kr/release-notes/v0.1.0.md) | [English](./v0.1.0.md)

These are draft release notes for the initial public Career Feed release line. They do not imply that a GitHub release tag already exists.

## Summary

v0.1.0 introduces fork-based GitHub Actions automation for backend learning, Korean dev/AI news review, weekly career site radar, and PS progress marking.

## Highlights

- Daily Backend Brief workflow.
- Korea Dev/AI News Daily workflow.
- Backend Career Site Radar workflow.
- Validation scripts and fixtures.
- Korean and English documentation trees.

## Safety

Discord delivery is disabled by default, dry-run artifacts are the first review surface, and secrets must remain in GitHub Secrets or environment variables.

## Setup

Start from [Fork Setup Guide](../getting-started/fork-setup.md), then review [Runtime Configuration](../getting-started/runtime-configuration.md).

## Known limitations

No persistent server, database, dashboard, Discord Gateway Bot, Slash Command service, account system, or recruiting-matching feature is included.

## Maintainer notes

Before cutting a release, run `./scripts/validate.sh`, confirm docs links, confirm no generated reports are staged, and update release status in README if a real tag is created.
