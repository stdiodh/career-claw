# Daily Backend Brief Example

> Language: [한국어](../../kr/examples/daily-backend-brief.example.md) | [English](./daily-backend-brief.example.md)

This example shows the shape of a Daily Backend Brief. Real workflow output is generated under `reports/briefs/kr-tech-daily.md`.

## Backend Study Topic

- Topic: Kotlin null-safety at Spring MVC request boundaries.
- Practice: compare nullable request parameters, validation annotations, and controller method signatures.
- References: official Spring and Kotlin documentation only.

## PS Routine

- Problem source: configured Programmers curriculum.
- Output: one weekly routine item and progress state.
- Note: Career Feed does not crawl submissions or Programmers account data.

## OSS Contribution Preparation

- If a safe recent issue exists, the brief includes repository, issue URL, contribution type, and local check hints.
- If no safe issue exists, the brief renders a preparation routine without forcing an old issue.

## Practical Backend Knowledge

- Situation: a junior backend task or failure mode.
- Action: concrete practice steps.
- Done criteria: observable result that can be reviewed in a local project.
