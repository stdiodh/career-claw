# Backend Career Site Radar Example

> Language: [한국어](../../kr/examples/career-site-radar.example.md) | [English](./career-site-radar.example.md)

This example shows the weekly career site radar shape. The workflow checks configured public sites and renders a review artifact.

## Sites to Check

- Company career pages.
- Internship and trainee pages.
- Public activities, hackathons, contests, and developer events.
- Sources listed in `configs/weekly-career-site-radar.json`.

## Review Criteria

Check whether the link is public, current, relevant to backend learners, and safe to include in a Discord-delivered summary.
