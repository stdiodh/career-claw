# Dev News Daily Example

> Language: [한국어](../../kr/examples/korea-dev-ai-news-daily.example.md) | [English](./korea-dev-ai-news-daily.example.md)

This example shows the expected structure for Dev News Daily. Sparse or empty days can still be valid when policy allows them.

## News to Review

- Include 3 to 5 selected items when enough qualified sources exist.
- Separate developer technology relevance from investment or market context.
- Use stable source URLs and avoid duplicate links.

## Quality Check

Validation checks duplicate URLs, investment-advice wording, missing risk context, weak growth actions, and required quality sections.

## Before Discord Delivery

Review the Markdown artifact, quality report, token budget report, and run summary. Keep `dry_run=true` until the output is acceptable.
