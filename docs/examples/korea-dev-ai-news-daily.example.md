# Korea Dev/AI News Daily Example

Career Feed가 생성할 수 있는 한국 개발/AI 뉴스 브리핑 형태를 설명하기 위한 예시입니다.

## 오늘 볼 개발/AI 뉴스

- 국내 클라우드 서비스의 장애 대응 공개 기록을 읽고, 백엔드 운영 관점에서 배울 점을 정리합니다.
- Java, Kotlin, Spring 생태계에 영향을 줄 수 있는 도구 릴리스나 보안 공지를 확인합니다.
- AI 서비스 업데이트는 백엔드 개발자의 업무 흐름, API 사용, 비용 관리 관점에서만 요약합니다.

## 품질 확인

- 출처가 공개 URL인지 확인합니다.
- 투자 조언이나 가격 전망처럼 보이는 문장은 제외합니다.
- 같은 URL이나 같은 사건을 중복으로 넣지 않습니다.
- 뉴스가 적은 날은 sparse output으로 남기고 억지로 채우지 않습니다.

## Discord 전송 전 확인

- validation report가 통과했는지 확인합니다.
- private channel, webhook URL, API key가 본문에 들어가지 않았는지 확인합니다.
- 각 항목이 백엔드 학습자나 주니어 개발자가 오늘 읽을 이유를 담고 있는지 확인합니다.
