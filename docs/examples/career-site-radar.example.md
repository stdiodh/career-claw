# Backend Career Site Radar Example

이 문서는 Career Feed가 생성할 수 있는 커리어 사이트 레이더 형태를 설명하기 위한 예시입니다.

실제 공고나 마감일을 주장하지 않습니다.

## 확인할 정보

- 신입·주니어 백엔드 채용 공고
- 인턴십
- 대외활동
- 해커톤·공모전
- 기술 블로그 채용 연계 콘텐츠

## 확인 기준

- 공식 공고 URL이 있는가?
- 마감일이 명확한가?
- 백엔드 기술 스택이 명시되어 있는가?
- 지원 자격이 주니어에게 현실적인가?
- 채용 공고와 학습 계획을 연결할 수 있는가?

## 주의사항

- 마감일은 반드시 공식 공고에서 직접 확인합니다.
- 자동 생성 결과를 최종 정보로 사용하지 않습니다.
- 개인정보를 브리핑에 포함하지 않습니다.
