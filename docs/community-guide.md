# Community Guide

Career Feed는 개인 학습자뿐 아니라 Discord 스터디, 백엔드 멘토링 그룹, 주니어 개발자 커뮤니티에서도 재사용할 수 있도록 설계합니다.

## 어떻게 활용할 수 있나요?

- 개인 학습 루틴 점검
- Discord 스터디 daily briefing
- 백엔드 멘토링 주간 체크인
- 커리어 정보 레이더
- OSS 기여 후보 탐색
- 반복되는 질문의 공개 지식화

## 추천 운영 방식

### Daily Backend Brief

매일 학습 주제와 PS 루틴을 확인하는 용도로 사용합니다.

추천 사용 방식:

- 오늘 볼 백엔드 주제 1개 선택
- PS 문제 1개 풀이
- OSS 후보 1개 살펴보기
- 모르는 용어를 issue나 개인 노트에 기록

### Korea Dev/AI News Daily

한국 개발·AI 뉴스와 기술 흐름을 가볍게 확인하는 용도로 사용합니다.

추천 사용 방식:

- 모든 뉴스를 깊게 읽기보다 관심 있는 항목만 선택
- 채용·기술 수요와 연결되는 키워드 기록
- 과장된 트렌드보다 실제 학습 계획에 연결되는 내용만 반영

### Backend Career Site Radar

주간 커리어 점검용으로 사용합니다.

추천 사용 방식:

- 공식 공고 URL 확인
- 마감일 확인
- 기술 스택과 지원 자격 확인
- 현재 학습 계획과 연결되는 요구사항 기록

### OSS 후보

OSS 후보는 실제 기여 전 반드시 직접 확인해야 합니다.

확인할 것:

- CONTRIBUTING 문서
- build guide
- test command
- issue context
- maintainer 응답 흐름
- 최근 활동 여부

## 주의사항

- 브리핑은 의사결정의 보조 자료이며 최종 판단은 사람이 해야 합니다.
- 채용, 인턴, 대외활동 정보는 마감일과 공식 공고를 직접 확인해야 합니다.
- OSS 후보는 외부 프로젝트에 부담을 주지 않는 방식으로 접근해야 합니다.
- 자동 생성 결과를 그대로 공식 답변처럼 사용하지 않습니다.
- 개인정보나 민감한 커리어 정보는 공개 issue에 남기지 않습니다.
