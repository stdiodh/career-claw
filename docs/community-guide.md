# Community Guide

## Career Feed를 어떻게 활용할 수 있나요?

Career Feed는 개인 학습자, Discord 스터디, 백엔드 멘토링 그룹이 반복 가능한 성장 피드를 운영할 때 참고할 수 있는 초기 단계의 오픈소스 workflow입니다.

## 활용 방식

- 개인 학습 루틴
- Discord 스터디 브리핑
- 백엔드 멘토링 주간 체크인
- 커리어 정보 레이더
- OSS 기여 후보 탐색

## 추천 운영 방식

- Daily Backend Brief는 학습 루틴 점검용으로 사용합니다.
- Korea Dev/AI News Daily는 기술 트렌드 관찰용으로 사용합니다.
- Backend Career Site Radar는 주간 커리어 점검용으로 사용합니다.
- OSS 후보는 실제 기여 전 저장소의 `CONTRIBUTING`, build guide, issue context를 직접 확인합니다.

## 주의사항

- 브리핑은 의사결정의 보조 자료이며, 최종 판단은 사람이 해야 합니다.
- 채용/인턴/대외활동 정보는 마감일과 공식 공고를 직접 확인해야 합니다.
- OSS 후보는 외부 프로젝트에 부담을 주지 않는 방식으로 접근해야 합니다.
- 자동 생성 결과를 그대로 공식 답변처럼 사용하지 않습니다.
