# Source Policy

> Language: [한국어](./source-policy.md) | [English](../../en/project/source-policy.md)

이 정책은 contributor가 유용한 공개 source를 제안하고 low-quality 또는 unsafe input을 피하도록 돕습니다.

공통 baseline은 [Source Policy](../../project/source-policy.md)을 참고하세요.

## Good Sources

좋은 source는 공개적이고, 안정적이고, 관련성이 있고, maintainer가 검토할 수 있어야 합니다.

예시:

- official documentation
- official engineering blogs
- public GitHub repositories and issues
- public career pages
- reliable technology media
- public RSS or Atom feeds

## Sources To Avoid

아래 source는 피합니다.

- private login context가 필요한 source
- private Discord, repository, personal detail을 노출하는 source
- SEO, affiliate, referral, advertorial traffic이 주목적인 source
- 원문 없이 중복 게시만 하는 source
- risk context 없이 investment advice나 price movement만 강조하는 source
- maintainer가 검증할 수 없는 source

## Locale Notes

`ko-KR`은 기본 지원 locale이며 한국 source assumption을 사용할 수 있습니다.

`en-US`는 v0.2 foundation / experimental preset입니다. source suggestion은 환영하지만, 근거가 생기기 전까지 mature preset으로 설명하지 않습니다.

## Issue Checklist

Source를 제안할 때 아래를 포함해 주세요.

- source URL
- locale
- source type
- update cadence
- reliability tier
- target audience에 도움이 되는 이유
- known risks

secret, webhook URL, API key, private link, personal identifier는 포함하지 마세요.
