# Backend Career Site Radar Example

> Language: [한국어](./career-site-radar.example.md) | [English](../../en/examples/career-site-radar.example.md)

Career Feed가 생성할 수 있는 커리어 사이트 레이더 형태를 설명하기 위한 예시입니다.

## 확인할 정보

- 신입/주니어 백엔드 채용 공고
- 인턴십
- 대외활동
- 해커톤/공모전
- 기술 블로그 채용 연계 콘텐츠

## 확인 기준

- 공식 공고 URL이 있는가?
- 마감일이 명확한가?
- 백엔드 기술 스택이 명시되어 있는가?
- 지원 자격이 주니어에게 현실적인가?
