# v0.1.0 Release Notes

> Language: [한국어](./v0.1.0.md) | [English](../../en/release-notes/v0.1.0.md)

## Summary

Career Feed v0.1.0 is the first open-source ready release focused on fork-based usage.

It helps Java/Kotlin backend developers generate scheduled learning, news, career, and OSS contribution briefs through GitHub Actions and Discord webhooks.

This is an initial public release, not a guarantee of production-grade stability or perfect source accuracy.

Users should review generated artifacts and source links before acting on a brief.

릴리스 기준은 [`v0.1.0` GitHub Release](https://github.com/stdiodh/career-feed/releases/tag/v0.1.0)와 같은 tag의 source tree입니다.

## Highlights

- Fork-first setup flow
- OSS readiness and impact evidence in README
- Redacted demo evidence for dry-run, artifacts, validation, and Discord output

- GitHub Actions Secrets and Variables separation

- Generated brief validation before Discord delivery
- Demo and sample output documentation
- Contributor task ideas and release checklist

## Safety

- Secrets and Variables are documented separately.
- Discord webhook URLs are treated as secrets.
- OSS candidates use `created_at` recency filtering.
- Generated briefs are validated before Discord delivery.
- Safe candidate fallback is used when no recent OSS issue is available.
- The project does not auto-claim, auto-comment, auto-assign, auto-label, or open PRs on external GitHub repositories.

## Setup

1. Fork the repository.
2. Enable GitHub Actions in the fork.
3. Configure GitHub Actions Secrets.
4. Configure GitHub Actions Variables.
5. Run a Daily workflow with `dry_run=true`.
6. Review generated artifacts and validation reports.
7. Set `CAREER_FEED_DISCORD_DELIVERY_ENABLED=true` only after dry-run review.
8. Run with delivery enabled or wait for the scheduled runtime gate.

See [Fork Setup Guide](../getting-started/fork-setup.md) for the full walkthrough.

## Known limitations

- No stars, downloads, active users, or adoption metrics are claimed for this release.
- External source availability may affect generated content.
- GitHub Actions schedule timing is not real-time.
- Generated briefs are a reviewable starting point, not final career advice.
- Users should review source links before acting.
- OSS candidate recommendations require human confirmation before contributing.
- Career Feed does not provide a hosted dashboard, Gateway Bot, Slash Command, database, or multi-user SaaS service.
