# v0.2.0 Release Notes

> Language: [한국어](./v0.2.0.md) | [English](../../en/release-notes/v0.2.0.md)

Career Feed v0.2.0은 v0.1.0의 fork 기반 workflow baseline 위에 locale-aware foundation을 추가한 릴리스입니다.

v0.2.0 릴리스 기준은 [shared v0.2.0 release baseline](../../project/release-v0.2.0.md)에 정리되어 있습니다.

## Summary

v0.2.0은 `ko-KR`을 기본 지원 locale로 유지하고, `en-US`를 foundation / experimental preset으로 추가합니다.

locale별 config, prompt, artifact path, Discord webhook Secret 이름, provider preset 이름을 도입했습니다.

## What Changed

- `configs/locales/ko-KR/`와 `configs/locales/en-US/`를 추가했습니다.
- `scripts/locale_config.py`로 locale matrix와 runtime path를 해석합니다.
- daily workflow canonical artifact path를 `reports/briefs/{locale}/`, `reports/candidates/{locale}/`, `reports/ops/{locale}/`로 정리했습니다.
- locale-specific Discord webhook Secret 이름을 추가했습니다.
- `ko-KR` legacy webhook fallback 이름을 유지했습니다.
- v0.2 compatibility window 동안 `ko-KR` legacy mirror artifact를 유지합니다.
- `en-US` prompt, source config, audience profile, validation fixture를 추가했습니다.
- Naver, RSS, GitHub, Brave Search provider preset을 문서화했습니다.

## Upgrade Notes

기존 `ko-KR` fork 사용자는 v0.2.x 동안 legacy daily webhook fallback Secret 이름을 계속 사용할 수 있습니다.

새 fork는 locale-specific Secret 이름과 canonical locale artifact path를 사용하는 것을 권장합니다.

`en-US`를 테스트하려면 `CAREER_FEED_ENABLED_LOCALES=ko-KR,en-US`를 설정하고, Discord delivery를 켜기 전에 `en-US`용 webhook Secret을 함께 등록합니다.

## Known Limitations

- `en-US`는 아직 foundation/experimental preset입니다.
- Backend Career Site Radar는 `ko-KR` 중심입니다.
- Provider marker module은 있지만 provider 구현이 collector에서 완전히 분리되지는 않았습니다.
- adoption, production usage, star, download, active-user metric은 주장하지 않습니다.
