# Archive

This directory keeps documents that are useful for historical context but are not part of the primary user onboarding flow.

Archived documents are not the source of truth for current setup, workflow behavior, or contribution policy.

For current documentation, start with:

- [Documentation Index](../README.md)
- [Fork Setup Guide](../getting-started/fork-setup.md)
- [Runtime Configuration](../getting-started/runtime-configuration.md)
- [Usage Guide](../getting-started/usage.md)
- [OSS Candidate Policy](../policies/oss-candidate-policy.md)

## Rules

- Do not link archived documents from the README landing page unless there is a strong reason.
- Do not treat archived documents as current behavior.
- If an archived document contains useful current content, move that content into a canonical document first.
- If an archived document becomes misleading and has no historical value, remove it in a separate cleanup.
