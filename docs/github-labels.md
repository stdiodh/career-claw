# Suggested GitHub Labels

Career Feed에서 issue와 PR을 분류할 때 사용할 수 있는 label 제안입니다.

| Label | Purpose |
| --- | --- |
| `question` | 백엔드 커리어 질문 |
| `backend-career` | 백엔드 학습·커리어 고민 |
| `source` | 정보 출처 제안 |
| `oss-candidate` | OSS 후보 제안 |
| `good-first-issue` | 초보자 친화 후보 |
| `documentation` | 문서 개선 |
| `bug` | 수집·검증 오류 |
| `enhancement` | 개선 제안 |
| `security` | 보안·민감 정보 관련 |

Labels는 프로젝트 운영에 맞게 조정할 수 있습니다.

GitHub CLI가 인증되어 있다면 maintainer가 직접 label을 생성할 수 있습니다. 이 문서는 label 생성을 자동으로 수행하지 않습니다.
