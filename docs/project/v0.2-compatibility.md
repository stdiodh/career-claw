# v0.2 Compatibility Notes

These notes define the compatibility window for the v0.2.x release line.

## Compatibility Goal

v0.2.x should let existing `ko-KR` fork users keep running while new users move toward locale-specific configuration.

Compatibility means preserving current behavior unless a later release intentionally documents a breaking change.

## Supported Locales

| Locale | v0.2.x status |
| --- | --- |
| `ko-KR` | Default supported locale |
| `en-US` | Foundation / experimental preset |

Unknown locale values fail during locale matrix resolution instead of silently falling back.

## Secret Compatibility

Preferred v0.2 daily webhook Secrets:

- `DISCORD_WEBHOOK_KO_KR_BACKEND_DAILY`
- `DISCORD_WEBHOOK_KO_KR_NEWS_DAILY`
- `DISCORD_WEBHOOK_EN_US_BACKEND_DAILY`
- `DISCORD_WEBHOOK_EN_US_NEWS_DAILY`

Legacy `ko-KR` fallback Secrets preserved during v0.2.x:

- `DISCORD_WEBHOOK_KR_TECH_DAILY`
- `DISCORD_WEBHOOK_KR_TECH_NEWS_DAILY`

Do not remove the legacy fallback without a documented breaking-release plan.

## Artifact Compatibility

Preferred v0.2 daily paths:

- `reports/briefs/{locale}/backend-daily.md`
- `reports/briefs/{locale}/news-daily.md`
- `reports/candidates/{locale}/`
- `reports/ops/{locale}/`

Legacy `ko-KR` mirror paths preserved during v0.2.x:

- `reports/briefs/kr-tech-daily.md`
- `reports/briefs/kr-tech-news-daily.md`
- `reports/briefs/kr-backend-career-weekly.md`

New docs, tests, and examples should use canonical locale-specific paths unless they are explicitly testing compatibility.

## Provider Compatibility

Provider names are non-sensitive Variables.

Provider credentials are Secrets.

Current defaults:

- `CAREER_FEED_SEARCH_PROVIDERS_KO_KR=naver,rss,github`
- `CAREER_FEED_SEARCH_PROVIDERS_EN_US=brave,rss,github`

Missing optional provider credentials should produce warnings or skipped enrichment paths, not leaked values.

## Workflow Compatibility

The current operational workflows are:

- `.github/workflows/backend-daily.yml`
- `.github/workflows/dev-news-daily.yml`
- `.github/workflows/backend-career-weekly.yml`
- `.github/workflows/mark-ps-solved.yml`

Do not reintroduce removed v0.1 workflow names as active workflows.

## Validation Expectations

Compatibility-sensitive changes should run:

```bash
git diff --check
python3 scripts/check-doc-format.py
./scripts/validate.sh
```

When changing locale behavior, also run:

```bash
python3 scripts/locale_config.py matrix
python3 scripts/locale_config.py paths --locale ko-KR --feed backend-daily
python3 scripts/locale_config.py paths --locale en-US --feed backend-daily
python3 scripts/locale_config.py paths --locale ko-KR --feed news-daily
python3 scripts/locale_config.py paths --locale en-US --feed news-daily
```

## Breaking Change Candidates For Later

These are not v0.2.x tasks unless explicitly planned:

- Removing `ko-KR` legacy webhook fallback names.
- Removing `ko-KR` legacy artifact mirrors.
- Renaming canonical daily artifact paths.
- Changing default locale away from `ko-KR`.
- Treating `en-US` as fully mature without provider evidence and validation coverage.
