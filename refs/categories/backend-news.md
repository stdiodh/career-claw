# Backend News

## 목적
백엔드 개발자가 실무에서 확인해야 할 언어, 프레임워크, 데이터베이스, 인프라 릴리스와 변경사항을 추적한다.

## 포함할 정보
- Kotlin, Java, Spring, Node.js, TypeScript, Go, Rust, Python 업데이트
- PostgreSQL, Redis, Kafka, Docker, Kubernetes 변경사항
- AWS, GCP 등 클라우드 서비스의 개발자 영향 공지
- 마이그레이션, LTS, breaking change, 성능 개선

## 제외할 정보
- 단순 컨퍼런스 홍보
- 실무 영향이 약한 일반 기술 칼럼
- 제품 마케팅성 글

## 출력 규칙
- 최대 3개만 출력
- 각 항목은 제목, 1줄 요약, 원본 URL, 출처, 발행일만 포함
- 긴 해설 금지
- 추측 금지
- 원문 확인이 필요하면 "원문 확인 필요"라고 표시
