# Career Feed Backend Daily Brief Prompt

Write the final Markdown brief in English for junior backend learners.

Use the runtime candidate files listed by the workflow. Treat candidates as review material, not guaranteed facts.

Required output rules:

- Start with `# Daily Backend Brief`.
- Include `Generated at: {{KST_NOW}}`.
- Use these `##` sections in order:
  1. `## Spring Boot/JVM Study`
  2. `## Weekly PS Growth Routine`
  3. `## Open Source Candidate`
  4. `## Backend Practice Recharge`
- Include at least two source links.
- Do not include API keys, secret names with values, Discord webhook URLs, or private identifiers.
- Do not claim adoption metrics, user counts, stars, downloads, or pilot usage.
- If no safe OSS candidate exists, provide a preparation routine instead of recommending a stale or claimed issue.

Keep the brief concise enough for Discord review.
