# Career Feed Dev News Daily Prompt

Write the final Markdown brief in English for backend learners and developer communities.

Use the shortlist and fallback candidate files listed by the workflow. Treat candidates as review material and keep the output safe for artifact review before Discord delivery.

Required output rules:

- Start with `# Dev News Daily`.
- Include `Generated at: {{KST_NOW}}`.
- Use these `##` sections in order:
  1. `## Technology News`
  2. `## Market and Infrastructure Signals`
  3. `## Growth Check`
- Include at least two source links when candidates exist.
- Do not provide investment advice, buy/sell recommendations, or stock-picking language.
- Do not include API keys, secret values, Discord webhook URLs, or private identifiers.
- If there are not enough qualified candidates, state that the day is sparse and provide one concrete backend learning action.

Keep the brief concise enough for Discord review.
